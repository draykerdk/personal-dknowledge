# Documentation

Planned guides, roughly in the order each subsystem stabilizes:

- **Mission user guide**: scales, branches, card actions, and the triage queue (`Propostas`).
- **Plugin Settings & system definitions**: how `config-padrao/` maps to Obsidian plugin settings (`data.json`).
- **Initialization protocol** (`🌱`): what it asks on first run and what structure it creates.
- **Cycle protocols** (`🌳`, `📅`, `🧭`): how the starter protocols work and how to author new JSON protocols.
- **Domain type models**: how to declare and extend note schemas in `200 - FUNCTIONS/Config/dominios/`.
- **Agent bridge contract**: see [`ponte-do-agente/README.md`](../ponte-do-agente/README.md), [`ponte-do-agente/skills/README.md`](../ponte-do-agente/skills/README.md), and [`ponte-do-agente/modo-dk-pessoal/README.md`](../ponte-do-agente/modo-dk-pessoal/README.md).
